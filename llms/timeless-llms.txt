# Timeless

> Timeless (Timeless Investments GmbH, Berlin) is a fractional-investment platform for collectibles — luxury watches, classic cars, sneakers, wine, art, and memorabilia. Users buy fractions of authenticated collectible assets starting at 50 EUR through the Timeless iOS/Android app. Backed by EQT Ventures. Timeless publishes no public developer portal or API: api.timeless.investments is a private authenticated backend (AWS API Gateway) with no public documentation.

Timeless is a consumer fintech mobile app; there is no public API surface, SDK, or developer documentation to integrate against.
